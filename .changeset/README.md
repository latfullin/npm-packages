# Changesets

Версии и CHANGELOG пакетов. Коротко: к изменению, которое должно попасть в релиз,
прикладывается файл-описание — `npx changeset`. Он спросит, какие пакеты задеты и
насколько поднять версию (patch / minor / major), и создаст здесь `.md`-файл.

Эти файлы накапливаются в ветках и мержатся в `main` вместе с кодом. Дальше
`.github/workflows/release.yml` сам поднимает версии, переписывает CHANGELOG пакетов
и открывает PR «Релиз». Мерж этого PR публикует пакеты на npm.

Подробнее — в README, раздел «Публикация на npm».
